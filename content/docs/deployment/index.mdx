Two things need doing that a development run does not require. Signals must be connected to a `ShutdownHandle` — Ulo installs no handlers, so an unwired process is killed rather than drained. And the listener should be reachable from outside the container, which means binding `0.0.0.0` rather than `127.0.0.1`.
