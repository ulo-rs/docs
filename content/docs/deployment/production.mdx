## Release build

```bash
cargo build --release
```

The compiled binary is in `target/release/<project-name>`. It has no runtime dependencies; ship the binary alone.

## Environment configuration

Set required environment variables before starting:

```bash
export DATABASE_URL="postgresql://user:pass@db-host:5432/myapp"
export JWT_SECRET="a-very-long-secret-key-at-least-32-chars"
export PORT=8080
export HOST=0.0.0.0

./target/release/my_api
```

Or use a `.env` file (if your application loads it with the `dotenv` crate):

```bash
# .env.production
DATABASE_URL=postgresql://...
JWT_SECRET=...
PORT=8080
```

## Graceful shutdown

Toni installs **no** signal handlers. A container runtime or systemd stops a process by sending SIGTERM and waiting; with nothing listening for it, the process is killed with requests in flight and the shutdown hooks never run.

Wire it by taking a `ShutdownHandle` after `bind()` and calling `shutdown()` from a task that waits on the signal:

```rust
use tokio::signal::unix::{signal, SignalKind};

app.bind().await?;

let shutdown = app.shutdown_handle();
tokio::spawn(async move {
    let mut sigterm = signal(SignalKind::terminate()).expect("failed to listen for SIGTERM");
    sigterm.recv().await;
    tracing::info!("SIGTERM received, shutting down");
    shutdown.shutdown();
});

app.run().await;
```

`shutdown()` takes no argument, and `before_application_shutdown` and `on_application_shutdown` receive `None` for their `signal` parameter on every path — log the signal name where you catch it.

On the shutdown signal, `run()` closes the adapters first so in-flight requests drain, then runs the shutdown hooks in order: `on_module_destroy` → `before_application_shutdown` → `on_application_shutdown`. `ShutdownHandle` is cloneable and `shutdown()` is idempotent, so any task can trigger it.

[Graceful shutdown](/docs/techniques/graceful-shutdown) covers the wiring in full — catching SIGINT and Windows Ctrl+C from the same task, and the rest of `ShutdownHandle`. The runnable version is [`examples/graceful_shutdown.rs`](https://github.com/ifeanyi-ugwu/toni-rs/blob/master/examples/graceful_shutdown.rs).

## Listening on all interfaces

For production, listen on `0.0.0.0` (all interfaces) rather than `127.0.0.1` (loopback only):

```rust
app.use_http_adapter(AxumAdapter::new(), ("0.0.0.0", 8080)).unwrap();
app.start().await?;
```

Or read the host and port from configuration:

```rust
let host = std::env::var("HOST").unwrap_or_else(|_| "0.0.0.0".to_string());
let port: u16 = std::env::var("PORT")
    .unwrap_or_else(|_| "8080".to_string())
    .parse()
    .expect("PORT must be a number");

app.use_http_adapter(AxumAdapter::new(), (host, port)).unwrap();
app.start().await?;
```

<Callout type="info" title="bind() is refuse-or-none">
`start()` returns `Result<()>`. Underneath, `bind()` acquires sockets for **every** declared transport (HTTP, WebSocket, RPC, gRPC) and refuses if any of them fails: the error is a `StartupError` naming the transport, any sockets already acquired are closed, and nothing serves. Port conflicts, permission denials, and configuration errors surface here rather than panicking inside the server. Startup-hook failures surface earlier, as `StartupError::HookFailed` from `create`: an `on_module_init` that returns `Err`, or a database [startup check](/docs/database/seaorm#startup-check) that cannot reach its server.
</Callout>

## Systemd service

A basic systemd unit file:

```ini
[Unit]
Description=My Toni API
After=network.target

[Service]
Type=simple
User=api
WorkingDirectory=/opt/myapp
ExecStart=/opt/myapp/my_api
EnvironmentFile=/opt/myapp/.env
Restart=on-failure
RestartSec=5s

[Install]
WantedBy=multi-user.target
```

```bash
sudo systemctl enable myapp
sudo systemctl start myapp
sudo journalctl -u myapp -f
```

`systemctl stop` sends SIGTERM, so the [graceful shutdown wiring above](#graceful-shutdown) is what makes it a clean stop.

One caveat on `Restart=on-failure`: a serve loop that dies at runtime closes the whole application — the remaining transports drain and the process exits **cleanly**, status 0. `on-failure` will not restart a clean exit, so use `Restart=always` if a self-closing application should come back.

Logs reach `journalctl` without any setup: the framework's default `tracing` subscriber writes to stderr at `info` level, adjustable per deployment with `RUST_LOG` in the environment file. See [Logging](/docs/techniques/logging).

## Socket activation

systemd can own the listening socket and pass it to the service. The socket stays open across restarts, so requests arriving while the service is down wait in the kernel accept queue instead of being refused. Declare it in a `.socket` unit:

```ini title="/etc/systemd/system/myapp.socket"
[Socket]
ListenStream=8080

[Install]
WantedBy=sockets.target
```

```bash
sudo systemctl enable --now myapp.socket
```

systemd announces the inherited socket through `LISTEN_FDS`, which the framework does not read itself. Adopt the socket with the [`listenfd`](https://docs.rs/listenfd) crate and hand it to `use_http_adapter` as a `BindTarget`, keeping a fallback branch so the binary still runs on its own — under a debugger, in tests, or from `cargo run`:

```rust
use listenfd::ListenFd;
use toni::BindTarget;

/// Take the inherited socket if there is one, otherwise bind normally.
fn http_target() -> anyhow::Result<BindTarget> {
    let mut fds = ListenFd::from_env();
    match fds.take_tcp_listener(0)? {
        Some(listener) => Ok(listener.into()),
        None => Ok(("0.0.0.0", 8080).into()),
    }
}

let mut app = ToniFactory::new().create_with(AppModule).await?;
app.use_http_adapter(AxumAdapter::new(), http_target()?)?;
app.start().await?;
```

`toni dev --listen` announces its socket over the same protocol, so this adoption code serves development and production unchanged — see the [development workflow](/docs/getting-started/development-workflow). All HTTP adapters accept a pre-bound listener except rocket, which refuses it at `bind()`. See [Bind targets](/docs/techniques/bind-targets) for the full `BindTarget` API.

## Performance tuning (Axum / Tokio)

```rust
fn main() -> anyhow::Result<()> {
    tokio::runtime::Builder::new_multi_thread()
        .worker_threads(num_cpus::get())
        .enable_all()
        .build()
        .unwrap()
        .block_on(async {
            let mut app = ToniFactory::new().create_with(AppModule).await?;
            app.use_http_adapter(AxumAdapter::new(), ("0.0.0.0", 8080)).unwrap();
            app.start().await
        })
}
```

```toml title="Cargo.toml"
[dependencies]
num_cpus = "1"
```

## Reverse proxy (nginx)

Run the Toni server on a local port and proxy from nginx:

```nginx
server {
    listen 80;
    server_name api.example.com;

    location / {
        proxy_pass http://127.0.0.1:8080;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
    }

    # WebSocket support
    location /ws {
        proxy_pass http://127.0.0.1:8080;
        proxy_http_version 1.1;
        proxy_set_header Upgrade $http_upgrade;
        proxy_set_header Connection "upgrade";
    }
}
```

Enable HTTPS via Certbot:

```bash
sudo certbot --nginx -d api.example.com
```
