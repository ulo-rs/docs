---
title: Testing
description: Unit tests against plain structs, and integration tests against a bound application.
---

Most of a Ulo application is testable without the framework. A service is a struct — construct it and call the method. Reach for the container only when the test is about something the container does: token resolution, request scope, or a lifecycle hook.
