title: API Reference
description: The surfaces docs.rs cannot describe on its own — macro forms, wire envelopes, and adapter behaviour.
---

[docs.rs](https://docs.rs/ulo) is the complete, generated reference for every type in every crate, and it is always current with the published version. These pages exist for what a generated reference cannot show: the shape a procedural macro expects, the JSON an RPC transport puts on the wire, and the behaviour an adapter has that its type signature does not state.

A crate has a page here when an application writes its names directly and that surface is more than one constructor call — the framework crates, the tools, and the adapters and transports carrying knobs, a wire format, or capability gaps of their own. Every adapter and transport also has a guide chapter: [HTTP adapters](/docs/http-adapters) and [Microservices](/docs/microservices) carry the choice between them and the worked setup, and for the crates without a page here they are the whole reference alongside docs.rs.
