---
title: Rooms
description: Group WebSocket clients into named rooms and broadcast to specific groups.
---

Rooms let you group clients by a logical name and broadcast to a specific group. Common use cases: chat channels, game lobbies, collaboration sessions, topic subscriptions.

Use `BroadcastService` (from `BroadcastModule`) to manage room membership and send targeted messages. Rooms are created implicitly: joining a room that doesn't exist creates it, and membership is cleaned up when a client disconnects. Membership answers who is in a group; per-connection state — a nickname, an authenticated user — belongs in that connection's [`Session`](/docs/websocket/gateways#session) rather than in a map of your own keyed by client id.

## Basic room gateway

Clients send JSON frames like `{"event": "join", "data": {"room": "lobby"}}` — the `event` field routes to the handler, and the handler parses the `data` payload from the full frame:

```rust
use toni::websocket::{
    BroadcastModule, BroadcastService, WsClient, WsError, WsHandlerOutput, WsMessage,
};
use toni::WsHandlerResult;
use toni::{module, new, on_connect, on_disconnect, subscriptions, websocket_gateway};

#[websocket_gateway("/rooms")]
pub struct RoomGateway {
    #[inject]
    broadcast: BroadcastService,
}

impl RoomGateway {
    #[on_connect]
    async fn handle_connect(&self, client: &WsClient) -> Result<(), WsError> {
        self.broadcast
            .to_client(&client.id)
            .send(WsMessage::text(format!("Connected as {}", client.id)))
            .await
            .ok();
        Ok(())
    }

    #[on_disconnect]
    async fn handle_disconnect(&self, client: &WsClient) {
        // Notify all rooms the client was in
        let rooms = self.broadcast.get_client_rooms(&client.id);
        for room in rooms {
            self.broadcast
                .to_room(&room)
                .send(WsMessage::text(format!("{} left", client.id)))
                .await
                .ok();
        }
    }
}

#[subscriptions]
impl RoomGateway {
    #[new]
    pub fn new(broadcast: BroadcastService) -> Self {
        Self { broadcast }
    }

    fn parse_field(message: &WsMessage, field: &str) -> Result<String, WsError> {
        let text = message
            .as_text()
            .ok_or_else(|| WsError::InvalidMessage("Expected text message".into()))?;
        let data: serde_json::Value = serde_json::from_str(text)
            .map_err(|e| WsError::InvalidMessage(format!("Invalid JSON: {}", e)))?;
        data["data"][field]
            .as_str()
            .map(String::from)
            .ok_or_else(|| WsError::InvalidMessage(format!("Missing {} field", field)))
    }

    #[subscribe_message("join")]
    async fn handle_join(&self, client: WsClient, message: WsMessage) -> WsHandlerResult {
        let room = Self::parse_field(&message, "room")?;

        self.broadcast.join_room(&client.id, &room)?;

        // Notify everyone in the room, including the joiner
        self.broadcast
            .to_room(&room)
            .send(WsMessage::text(format!("{} joined {}", client.id, room)))
            .await?;

        Ok(WsHandlerOutput::Empty)
    }

    #[subscribe_message("leave")]
    async fn handle_leave(&self, client: WsClient, message: WsMessage) -> WsHandlerResult {
        let room = Self::parse_field(&message, "room")?;

        self.broadcast.leave_room(&client.id, &room)?;

        self.broadcast
            .to_client(&client.id)
            .send(WsMessage::text(format!("Left room: {}", room)))
            .await?;

        Ok(WsHandlerOutput::Empty)
    }

    #[subscribe_message("message")]
    async fn handle_message(&self, client: WsClient, message: WsMessage) -> WsHandlerResult {
        let room = Self::parse_field(&message, "room")?;
        let text = Self::parse_field(&message, "text")?;

        self.broadcast
            .to_room(&room)
            .send(WsMessage::text(format!("[{}] {}: {}", room, client.id, text)))
            .await?;

        Ok(WsHandlerOutput::Empty)
    }
}

#[module(
    imports: [BroadcastModule::new()],
    providers: [RoomGateway],
)]
pub struct RoomsModule;
```

`join_room` and `.send()` return `Result<_, BroadcastError>`, which converts into `WsError` via `?` inside handlers.

`parse_field` above pulls one field out of the raw frame. A handler that wants the frame as a type takes `Payload<T>` instead — it deserializes the whole frame, so `T` carries the fields the frame carries — and `Validated<Payload<T>>` adds validation on top. See [Handler parameters](/docs/websocket/gateways#handler-parameters).

## BroadcastService API

```rust
// Room membership (sync — in-process state)
broadcast.join_room(&client_id, room) -> Result<(), BroadcastError>
broadcast.leave_room(&client_id, room) -> Result<(), BroadcastError>
broadcast.get_client_rooms(&client_id) -> Vec<String>
broadcast.get_room_clients(room) -> Vec<String>

// Targeting (returns a BroadcastTarget builder)
broadcast.to_all()               // all connected clients
broadcast.to_room(room)          // all clients in a named room
broadcast.to_client(client_id)   // a specific client (auto-room)
broadcast.except(client_id)      // all connected clients except one

// Target refinement
.and_room(room)                  // add a room (to_room targets): union of members
.in_namespace(ns)                // keep only clients in this namespace

// Sending (async, on the builder)
.send(WsMessage) -> Result<usize, BroadcastError>          // how many write channels accepted it
.send_event(event, data) -> Result<usize, BroadcastError>  // JSON: {"event": ..., "data": ...}
```

Both `join_room` and `leave_room` fail with `BroadcastError::ClientNotFound` when the client is not connected.

## Multi-room broadcasts

Chain rooms with `and_room` — clients in any of the rooms receive the message once:

```rust
self.broadcast
    .to_room("announcements")
    .and_room("general")
    .send(WsMessage::text("Server maintenance at midnight"))
    .await?;
```

## Private messages

Every client automatically joins a room named after its own ID on connect, so `to_client` is an ordinary room send:

```rust
#[subscribe_message("dm")]
async fn handle_dm(&self, client: WsClient, message: WsMessage) -> WsHandlerResult {
    let to = Self::parse_field(&message, "to")?;
    let text = Self::parse_field(&message, "text")?;

    self.broadcast
        .to_client(&to)
        .send(WsMessage::text(format!("DM from {}: {}", client.id, text)))
        .await?;

    Ok(WsHandlerOutput::Empty)
}
```

## Excluding the sender

`except(client_id)` targets every connected client except one:

```rust
// Everyone but the sender
self.broadcast
    .except(&client.id)
    .send(WsMessage::text(format!("{} did something", client.id)))
    .await?;
```

`except` is not room-scoped — it excludes one client from **all** connected clients. To broadcast to a room while skipping the sender (typing indicators, presence pings), iterate the room members:

```rust
#[subscribe_message("typing")]
async fn handle_typing(&self, client: WsClient, message: WsMessage) -> WsHandlerResult {
    let room = Self::parse_field(&message, "room")?;
    let msg = WsMessage::text(format!("{} is typing", client.id));

    for peer_id in self.broadcast.get_room_clients(&room) {
        if peer_id != client.id {
            self.broadcast.to_client(&peer_id).send(msg.clone()).await.ok();
        }
    }

    Ok(WsHandlerOutput::Empty)
}
```

## Broadcasting from services

`BroadcastService` is `Clone` — inject it into any service that needs to push to rooms:

```rust
use toni::websocket::{BroadcastService, WsMessage};
use toni::{injectable, new};

#[injectable]
pub struct ChatService {
    #[inject]
    broadcast: BroadcastService,
}

impl ChatService {
    #[new]
    pub fn new(broadcast: BroadcastService) -> Self {
        Self { broadcast }
    }

    pub async fn send_to_channel(&self, channel: &str, sender: &str, text: &str) {
        self.broadcast
            .to_room(channel)
            .send(WsMessage::text(format!("[{}] {}: {}", channel, sender, text)))
            .await
            .ok();
    }
}
```

Add it to the same module as the gateway:

```rust
#[module(
    imports: [BroadcastModule::new()],
    providers: [RoomGateway, ChatService],
)]
pub struct ChatModule;
```

Room membership lives in process memory. For a shared, cross-process view of rooms, see [Redis Broadcast](/docs/websocket/redis-broadcast).
