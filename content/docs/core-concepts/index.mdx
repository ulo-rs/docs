Four ideas carry a Ulo application. A **module** groups related pieces and decides what leaves it. A **controller** turns requests into calls. A **service** holds the logic. The **container** connects them, so nothing constructs its own dependencies.

Read them in order the first time — each builds on the last. [Modules](/docs/core-concepts/modules) is the one to start with, because every other declaration ends up listed in one.
