---
title: CLI Installation
description: Install the Ulo CLI to scaffold new projects and generate resources.
---

The Ulo CLI (`ulo-cli`) scaffolds new projects, generates CRUD resources (module + controller + service, wired in automatically), and runs the development watch loop from the terminal.

## Install

```bash
cargo install ulo-cli
```

The `ulo dev` command sits behind a default-on `dev` feature carrying the file-watcher dependencies. For a scaffolding-only install that builds faster:

```bash
cargo install ulo-cli --no-default-features
```

Verify installation — the version printed matches the installed crate version:

```bash
ulo --version
# ulo 0.1.2
```

## Updating

```bash
cargo install ulo-cli --force
```

## Requirements

- Rust 1.88 or later — the CLI declares it, and so do the crates it scaffolds into a new project
- Cargo on your PATH
